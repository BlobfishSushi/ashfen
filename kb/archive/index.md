# Shelved

Three different kinds of "not active," kept apart from the main `arcs/` tree so a scan of `arcs/index.md` reflects what's actually in play. None of it is deleted material — everything here is fully written and worth reading, it's just not where the story is currently going.

See `conventions.md` for the tag definitions (`[SHELVED]`, `[ALT-ENDING]`) that mark these pages. Not to be confused with `work/brainstorm/index.md` and `work/brainstorm/seeds.md` — those are for ideas still being explored, not yet decided either way. This folder is specifically for ideas that were tried and set aside.

## Shelved arcs

Experimental arcs the author drafted, then decided not to carry forward as part of the active story. Nothing downstream in the main timeline depends on them; where another page used to point to one of these as if it were going to happen, that page has been updated to say it was shelved instead.

| Arc | Why it's here |
|---|---|
| [The Mother's Framework / Training](the-mothers-framework-training.md) | Branch (B) of [The Smuggling Operation](../arcs/the-smuggling-operation.md) — the twins' parents finding out. The whole branch was shelved along with it. |
| [Ezekiel & Cookie's Nature](ezekiel-and-cookies-nature.md) | Downstream of Mother's Framework. Already demoted once the Holy Rot arc took over the Cookie's-nature reveal; shelved along with its parent branch. |
| [The Pestilence / The Lamb](the-pestilence-the-lamb.md) | The Fischer-family pestilence arc, and Aldric's link to his aunt Aura. Shelved along with The Fair, below. |
| [The Fischer Family / The Fair](the-fischer-family-the-fair.md) | Sets up The Pestilence / The Lamb. Both went together. |
| [The Morrison Building / The Serpent](the-morrison-building.md) | Self-contained arc, shelved on its own — nothing else depended on it either way. |
